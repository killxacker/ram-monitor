# ram-monitor

Terminalda real-time RAM monitoring vositasi (Python + psutil).

## O'rnatish
git clone https://github.com/USERNAME/ram-monitor.git
cd ram-monitor
pip install -r requirements.txt

## Ishlatish
python3 ram_monitor.py          # har soniyada yangilanadi
python3 ram_monitor.py -i 5     # har 5 soniyada
python3 ram_monitor.py -o       # bir marta ko'rsatish
